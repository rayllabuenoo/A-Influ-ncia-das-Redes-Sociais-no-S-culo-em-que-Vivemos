# A-Influ-ncia-das-Redes-Sociais-no-S-culo-em-que-Vivemos
 Este projeto aborda a influência das redes sociais no século XXI, destacando seus benefícios, como a comunicação e o acesso à informação, e seus desafios, como fake news e dependência digital. Desenvolvido em HTML e CSS, possui um design moderno com imagens e efeitos visuais.
